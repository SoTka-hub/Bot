# Telegram-бот ежедневной рассылки

Полноценный бот на **Python 3.11+** / **aiogram 3** для автоматической ежедневной публикации одного сообщения в список групповых чатов. Управление — через Telegram-панель владельца. Данные хранятся в **SQLite** и сохраняются после перезапуска.

## Возможности

- Ежедневная авторассылка по расписанию (APScheduler)
- Ручной запуск с предпросмотром и подтверждением
- Управление чатами: добавить / удалить / вкл-выкл / лимит / проверка доступа
- Управление сообщением: текст, HTML/MarkdownV2, фото, предпросмотр
- Защита от повторной отправки в рамках дневного цикла
- Продолжение рассылки после перезапуска (по истории)
- Отчёт владельцу + статистика и история
- Доступ только у `OWNER_ID` из `.env`

## 1. Создание бота в BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Укажите имя бота (отображаемое) и username (должен заканчиваться на `bot`).
4. BotFather пришлёт **токен** вида `1234567890:AAH...` — сохраните его.

Рекомендуется также:

- `/setprivacy` → Disable — если боту нужно видеть команды в группах (для `/add_chat`).
- Добавлять бота в группы как участника с правом **отправки сообщений**.

## 2. Как узнать свой Telegram ID

Напишите любому из ботов:

- [@userinfobot](https://t.me/userinfobot)
- [@getmyid_bot](https://t.me/getmyid_bot)

Скопируйте числовой `Id` — это `OWNER_ID`.

## 3. Настройка `.env`

```bash
copy .env.example .env
```

Отредактируйте `.env`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
OWNER_ID=ваш_telegram_id
DATABASE_PATH=data/bot.db
DEFAULT_TIMEZONE=Europe/Moscow
DEFAULT_ACTIVE_LIMIT=20
LOG_LEVEL=INFO
```

## 4. Установка зависимостей

Требуется Python **3.11+** (проверено на 3.14 с актуальным aiogram 3.x).

```bash
cd путь\к\проекту
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 5. Запуск бота

```bash
python bot.py
```

В консоли должно появиться сообщение о запуске бота. Откройте диалог с ботом и отправьте `/start`.

## 6. Добавление бота в группы

1. Добавьте бота в нужную группу/супергруппу.
2. Выдайте право **отправлять сообщения** (админ-права не обязательны, если в группе могут писать все участники).
3. Узнайте ID чата одним из способов:
   - перешлите сообщение из группы боту [@getidsbot](https://t.me/getidsbot) / аналогу;
   - либо находясь в группе, от имени владельца отправьте `/add_chat`.
4. В панели: **Управление чатами → Добавить чат** и введите ID (обычно вида `-100…`).

Бот **не вступает** в группы сам и не ищет чаты. Публикации идут только в явно добавленные чаты.

## 7. Первая настройка через панель

1. `/start` → **Управление сообщением** → создать текст (и при необходимости фото).
2. **Предпросмотр** — проверить вид сообщения.
3. **Управление чатами** — добавить чаты, проверить доступность, при необходимости изменить лимит активных (по умолчанию 20).
4. **Настройка расписания** — время и часовой пояс (`Europe/Moscow` по умолчанию).
5. **Запустить рассылку** — разовый тест с подтверждением.
6. Дождаться отчёта владельцу.

## 8. Автозапуск на сервере

### systemd (Linux)

Создайте файл `/etc/systemd/system/broadcast-bot.service`:

```ini
[Unit]
Description=Telegram Daily Broadcast Bot
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/broadcast-bot
Environment=PYTHONUNBUFFERED=1
ExecStart=/opt/broadcast-bot/.venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now broadcast-bot
sudo systemctl status broadcast-bot
```

### Windows (Планировщик заданий)

1. Создайте задачу «При входе в систему» / «При запуске».
2. Действие: запуск  
   `C:\путь\к\.venv\Scripts\python.exe`  
   с аргументом `bot.py` и рабочей папкой проекта.

### screen / tmux (быстрый вариант)

```bash
screen -S broadcast-bot
source .venv/bin/activate
python bot.py
# Ctrl+A, D — отсоединиться
```

## Защита от повторной отправки

- Каждая успешная отправка пишется в `send_logs` с `cycle_date` (дата в часовом поясе настроек).
- В рамках одного дня повторная отправка в тот же чат **не выполняется**.
- После резапуска бот продолжает только по чатам без успешной записи за текущий цикл.
- Планировщик: `max_instances=1` + asyncio-блокировка сервиса рассылки.

## Ограничения и безопасность

- Соблюдаются лимиты Telegram Bot API (`RetryAfter` обрабатывается паузой).
- При ошибке в одном чате рассылка продолжается по остальным.
- Админ-функции доступны только `OWNER_ID`.
- Бот не обходит ограничения Telegram, не использует несколько аккаунтов и не вступает в группы автоматически.
